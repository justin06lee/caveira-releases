# caveira-releases

**Release binaries for caveira. Source is closed.**

</div>

---

Install the terminal client on macOS or Linux:

```sh
curl -fsSL https://caveira.app/install.sh | sh
```

The macOS app is `caveira.dmg` on the [latest release](https://github.com/justin06lee/caveira-releases/releases/latest), or at [caveira.app/download/macos](https://caveira.app/download/macos). Each release's `checksums.txt` has the SHA-256 of every file in it.
